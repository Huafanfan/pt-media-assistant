## 决策记录

- **持久化归属：家庭共享**（用户 2026-09-12 确认）。这是单用户家庭服务，已看与偏好全局一份，设备间一致；不引入设备身份层。
- **持久化实现**：JSON 文件 + 临时文件 + `rename` 原子写 + 写入串行化；`PT_MEDIA_DATA_DIR`（容器 `/data` 命名卷；本地默认 `.data/app`）。schema 带 `version`，损坏文件重命名保留（不静默覆盖空文件），错误在状态页可见。
- **直搜边界**：直搜是显式子模式，不改变搜索页 media-first 默认；直搜结果不进入作品详情面板，仍走同一预检/确认边界。
- **任务操作边界**：哈希必须匹配 qBittorrent 真实格式（32–64 位字母数字）；客户端不能提交 `all`；移除只调 `deleteFiles=false`。
- **qB 兼容**：按 `webapiVersion` 选择 `stop/start`（5.x / API ≥ 2.11）或 `pause/resume`（4.6.x）；仅在主端点 404 时做一次兼容回退，不盲目重试。
- **状态页边界**：API key 存在只报告“已配置”，不主动发模型/搜索请求判断可用性；健康轮询不产生付费调用。
