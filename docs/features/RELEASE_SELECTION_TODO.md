## 2. 确定性解析与覆盖（依赖 1）

- [ ] 提取分辨率、来源类型、编码、动态范围、字幕和音轨，并附证据。
- [ ] 支持 SxxExx、集数区间、中文季集、单季/多季合集；保留无法识别原文。
- [ ] 支持综艺期数、日期、年份、上下段、正片/加更/纯享等标签。
- [ ] 明确“Complete/全集”只是声明，连载“更新至”不能作为完整证明。
- [ ] 实现范围交集、目标覆盖、额外范围、重叠；不同编号空间不强行映射。
- [ ] 展示候选间补齐线索，证据不足不说补齐成功，也不推断用户库存。
- [ ] 编写解析与覆盖 fixture，覆盖异常长标题、巨大区间、缺失和冲突。

完成条件：同输入输出稳定，每项识别有证据；错误季、节目版本不合并。

## 3. 统一规则排序服务（依赖 2）

- [ ] 盘点并复用现有 AI recommendation 的匹配/排序职责，消除双套规则。
- [ ] 实现作品匹配门槛、硬过滤、覆盖/证据分组、可用性分区和组内排序。
- [ ] 固定均衡/规格/小体积预设，以及未知档位、平局处理的常量表。
- [ ] 推荐最多三个不同候选；没有合适候选时给明确原因，不凑数。
- [ ] 合集和单集不直接比较总量；平均每集体积仅在证据充分时计算。
- [ ] 全快照计算后分页，说明结果受当前候选上限限制。
- [ ] 排序接口校验会话、来源、快照引用、目标与偏好；不接受客户端伪造事实。
- [ ] 为直搜提供可引用快照或等价内部机制；作品未确认不产生确定首选。
- [ ] 覆盖快照失效、缓存失效、revision 冲突；不自动刷新索引器。

完成条件：相同目标/快照结果一致，硬条件违规为零，重排产生零次额外 PT 查询。

## 5. 按需 AI 辅助（依赖 3、4）

- [ ] 复用当前 provider；默认打开页面不调用模型。
- [ ] 实现“AI 帮我比较”和自然语言偏好草稿，应用条件前展示解析结果。
- [ ] 最多 12 个候选、标题长度和 token 上限，说明部分分析数量。
- [ ] 单次请求、20 秒超时、限流/并发上限、取消、结果缓存。
- [ ] 严格校验返回 ID、字段证据、允许转换与理由码，拒绝凭空事实。
- [ ] 验证后的信息回到服务端重排，不允许模型直接指定最终首选。
- [ ] 缺配置/超时/429/格式错误统一降级；无自动付费重试。
- [ ] 旧 revision 返回不覆盖新选择；取消后不继续处理。
- [ ] 只发送最小脱敏字段；增加使用说明，日志不含标题正文、凭据或私有地址。
- [ ] mock 测试提示注入、伪造 ID、虚构字幕/全集、错误证据及泄漏边界。

完成条件：AI 增强解释且不改变证据标准，无 AI 时主流程完整可用。

## 6. 必须通过的验收矩阵（依赖 1–5）

| ID | 输入/操作 | 预期 |
| --- | --- | --- |
| A01 | 同电影多个规格版本 | 给不同取舍的有限推荐与具体理由 |
| A02 | 同名不同年份 | 错误作品不成为首选 |
| A03 | 必须字幕/只免费，但字段未知 | 不算满足，展示原因 |
| A04 | 第 2 季目标，混有第 1 季 | 不跨季推荐 |
| A05 | 整季目标，混有单集 | 分组，不用单集小体积压过整季 |
| A06 | 标题仅写全集 | 标记发布者声明，不说已核验完整 |
| A07 | 连载更新至 E08，总集数未知 | 不称全集，不给确定全季缺集数 |
| A08 | 多季合集只需一季 | 显示额外范围和总大小 |
| A09 | 两个重叠/互补合集 | 按证据解释，不推断用户库存或自动下载 |
| A10 | 综艺正片/加更/纯享 | 不互相当作等价候选 |
| A11 | 综艺日期与期号混用 | 无映射证据不合并 |
| A12 | 综艺上/下期、文件数多于期数 | 保留分段，不按文件数认定完整 |
| A13 | 全零做种或未知 | 可用性待确认，不保证速度 |
| A14 | 同候选重复满足推荐角色 | 去重，不强凑三项 |
| A15 | 翻页/过滤/重排 | 零次新增模型/PT 请求，先全量排后分页 |
| A16 | AI 关闭/超时/429/无效 JSON | 规则界面持续可用 |
| A17 | AI 虚构 ID/字幕/全集或标题注入 | 拒绝无据输出和越权行为 |
| A18 | 快速换季，旧 AI 响应后到 | 不覆盖当前目标或已选项 |
| A19 | 快照到期后选择下载 | 要求主动刷新，不提交旧引用 |
| A20 | 手机/键盘完成选片 | 范围与注意项可见，明确确认后仅一次 mock grab |
| A21 | 直搜没有作品身份 | 可整理候选但保持匹配待确认 |
| A22 | 条件互相冲突/无候选 | 不静默放宽，指出条件 |
